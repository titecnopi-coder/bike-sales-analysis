
# 🚴 Bike Sales Dashboard - Power BI

Dashboard interactivo desarrollado en Power BI para analizar ventas de bicicletas, categorías, productos más vendidos y rendimiento por tienda.

## 📊 Tecnologías utilizadas

* Python
* Pandas
* Power BI
* Data Visualization

## 🚀 Características

* Limpieza y transformación de datos
* Integración de múltiples tablas
* KPIs interactivos
* Dashboard visual profesional
